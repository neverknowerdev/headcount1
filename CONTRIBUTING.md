# Contributing to headcount1

Contributions are welcome: bug reports, fixes, features and documentation.

## Before your first pull request

headcount1 is published under the [GNU AGPL v3](LICENSE) and is also offered under commercial licenses. To make that possible, every contributor agrees to the [Contributor License Agreement](CLA.md). You keep the copyright in your work and give GMGM sp. z o.o. the right to license it.

To sign, add this sentence to the description of your first pull request:

> I have read the headcount1 Contributor License Agreement version 1.0 and I agree to it for this and all my future contributions.

We cannot merge a pull request from an outside contributor without it.

## Making a change

- Build and run instructions are in the [README](README.md).
- Run `go test ./...` and the frontend tests before you open a pull request.
- Keep a pull request to one change, and say what it does and how you checked it.
- If you include code or assets you did not write, name the source and its license in the pull request.

## Name and logo

The headcount1 name and logo are covered by the [trademark policy](TRADEMARKS.md), not by the AGPL.
